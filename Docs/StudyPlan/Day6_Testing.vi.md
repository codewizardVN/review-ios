# Day 6: Testing

## Goal

Ôn testing theo hướng hỗ trợ thiết kế hệ thống tốt hơn.

## Topics

- Unit test
- UI test
- Mocking
- Stubbing
- Test doubles
- Snapshot test
- Testable design

## What You Should Be Able To Explain

- Test nào nên viết, test nào không nên
- Vì sao testable architecture giúp team đi nhanh hơn
- Mock khác stub thế nào
- ViewModel nên test theo input/output ra sao
- UI test nên giữ ở mức nào để tránh flaky

## Practice Questions

- Nếu code rất khó test, vấn đề thường nằm ở đâu?
- Khi nào snapshot test có giá trị?
- Có nên test mọi thứ không?

## Senior Notes

- Senior mindset là tối ưu confidence per cost, không phải tăng số lượng test bằng mọi giá.
