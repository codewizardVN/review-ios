# Day 1: Swift Core

## Goal

Củng cố phần nền tảng quan trọng nhất của iOS senior.

## Topics

- `struct` vs `class`
- Value semantics vs reference semantics
- ARC
- Retain cycle
- Protocol-oriented programming
- Generics
- Error handling
- Access control

## What You Should Be Able To Explain

- Khi nào dùng `struct`, khi nào dùng `class`
- Tại sao value semantics giúp code an toàn hơn
- Retain cycle thường xuất hiện ở đâu
- Protocol khác gì inheritance trong thực tế
- Generic giúp tái sử dụng và type safety thế nào

## Practice Questions

- Vì sao Apple khuyến khích dùng `struct` nhiều hơn trong Swift?
- Closure capture list được dùng để giải quyết vấn đề gì?
- `mutating` có ý nghĩa gì với `struct`?
- `any` và `some` khác nhau thế nào?

## Senior Notes

- Không chỉ trả lời định nghĩa, cần nói được trade-off.
- Khi trả lời, luôn gắn với maintainability, readability, testability.
