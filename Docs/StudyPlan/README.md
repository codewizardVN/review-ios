# Senior iOS Study Plan

This study plan is designed to move from technical foundations to senior-level topics, with a practical review approach instead of disconnected theory.

## Suggested Order

1. Day 1: Swift Core
2. Day 2: Swift Concurrency
3. Day 3: SwiftUI
4. Day 4: Architecture
5. Day 5: Networking and Data Flow
6. Day 6: Testing
7. Day 7: Performance and Debugging
8. Day 8: Senior Review and Interview Scenarios

## How To Use

- Focus on one main topic per day.
- Review the theory quickly, then explain it again in your own words.
- If possible, write a mini sample or note down the trade-offs.
- Do not study in terms of APIs only. Study in terms of problem solving.

## Output Goal

After finishing this plan, you should be able to:

- Explain core Swift and SwiftUI concepts clearly.
- Present app architecture decisions and the reasons behind them.
- Describe testing, performance, and debugging strategies for production apps.
- Answer senior-level questions with reasoning and trade-off analysis.
