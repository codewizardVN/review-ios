# Day 4: Architecture

## Goal

Review architectural decisions from a practical perspective.

## Topics

- MVC
- MVVM
- Clean Architecture
- Coordinator
- Dependency injection
- Modularization
- Separation of concerns

## What You Should Be Able To Explain

- Why to choose MVVM or Clean Architecture
- When architecture has become over-engineered
- How dependency injection helps testing and scaling
- Whether module boundaries should be split by feature or by layer
- What problem Coordinator solves

## Practice Questions

- Should a small app use Clean Architecture?
- How do you spot a ViewModel that is getting too big?
- What criteria would you use to split the first module?

## Senior Notes

- There is no universally correct architecture.
- What matters is the ability to explain trade-offs, cost, complexity, and team fit.
