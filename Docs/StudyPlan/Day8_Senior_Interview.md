# Day 8: Senior Review and Interview Scenarios

## Goal

Bring everything together from the perspective of senior interviews and technical ownership.

## Topics

- System design for iOS apps
- Code review mindset
- Refactoring strategy
- Technical leadership
- Delivery trade-offs
- Backward compatibility
- Production debugging

## What You Should Be Able To Explain

- How you review a large PR
- When to refactor and when to leave the code as-is
- How you make technical decisions under deadline pressure
- How you support junior and mid-level engineers
- How you handle a production incident

## Practice Questions

- If the team wants to ship quickly but code quality is poor, what do you do?
- If there is architectural disagreement, how do you handle it?
- How do you balance technical debt and product delivery?

## Senior Notes

- This is where the difference between mid-level and senior becomes most visible.
- Focus on judgment, ownership, communication, and trade-offs.
