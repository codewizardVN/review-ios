# Day 4: Architecture

## Goal

Ôn các quyết định kiến trúc theo góc nhìn thực tế.

## Topics

- MVC
- MVVM
- Clean Architecture
- Coordinator
- Dependency injection
- Modularization
- Separation of concerns

## What You Should Be Able To Explain

- Vì sao chọn MVVM hay Clean Architecture
- Khi nào architecture đang bị over-engineered
- Dependency injection giúp testing và scale thế nào
- Module boundaries nên tách theo feature hay layer
- Coordinator giải quyết vấn đề gì

## Practice Questions

- App nhỏ có nên dùng Clean Architecture không?
- Làm sao nhận biết ViewModel đang phình quá mức?
- Bạn sẽ tách module đầu tiên dựa trên tiêu chí nào?

## Senior Notes

- Không có architecture “đúng tuyệt đối”.
- Điều quan trọng là giải thích được trade-off, cost, complexity, team fit.
