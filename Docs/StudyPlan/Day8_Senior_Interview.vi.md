# Day 8: Senior Review and Interview Scenarios

## Goal

Tổng hợp lại toàn bộ kiến thức dưới góc nhìn senior interview và technical ownership.

## Topics

- System design for iOS apps
- Code review mindset
- Refactoring strategy
- Technical leadership
- Delivery trade-offs
- Backward compatibility
- Production debugging

## What You Should Be Able To Explain

- Cách bạn review một PR lớn
- Khi nào nên refactor, khi nào nên giữ nguyên
- Cách bạn ra quyết định kỹ thuật trong bối cảnh deadline
- Cách bạn hỗ trợ team junior/mid-level
- Cách bạn xử lý incident production

## Practice Questions

- Nếu team muốn ship nhanh nhưng code quality đang tệ, bạn làm gì?
- Nếu có bất đồng về kiến trúc, bạn xử lý thế nào?
- Làm sao cân bằng technical debt và product delivery?

## Senior Notes

- Đây là phần tạo khác biệt rõ nhất giữa mid-level và senior.
- Tập trung vào judgment, ownership, communication, and trade-offs.
