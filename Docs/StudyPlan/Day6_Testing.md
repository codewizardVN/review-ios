# Day 6: Testing

## Goal

Review testing as a tool for better system design, not just verification.

## Topics

- Unit tests
- UI tests
- Mocking
- Stubbing
- Test doubles
- Snapshot tests
- Testable design

## What You Should Be Able To Explain

- Which tests should be written and which should not
- Why testable architecture helps teams move faster
- How mocks differ from stubs
- How to test a ViewModel through inputs and outputs
- How much UI testing is enough without becoming flaky

## Practice Questions

- If code is hard to test, where is the problem usually located?
- When do snapshot tests provide real value?
- Should everything be tested?

## Senior Notes

- A senior mindset optimizes confidence per cost, not test count at all costs.
