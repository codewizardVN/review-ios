# Day 1: Swift Core

## Goal

Strengthen the most important foundations for senior iOS development.

## Topics

- `struct` vs `class`
- Value semantics vs reference semantics
- ARC
- Retain cycles
- Protocol-oriented programming
- Generics
- Error handling
- Access control

## What You Should Be Able To Explain

- When to use `struct` and when to use `class`
- Why value semantics can make code safer
- Where retain cycles usually happen
- How protocols differ from inheritance in practice
- How generics improve reuse and type safety

## Practice Questions

- Why does Apple generally encourage heavy use of `struct` in Swift?
- What problem does a closure capture list solve?
- What does `mutating` mean for a `struct`?
- What is the difference between `any` and `some`?

## Senior Notes

- Do not stop at definitions. Explain the trade-offs.
- Tie your answers back to maintainability, readability, and testability.
