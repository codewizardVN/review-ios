# Day 7: Performance and Debugging

## Goal

Review the issues that usually appear when real apps become slow, memory-heavy, or crash.

## Topics

- Main-thread discipline
- Memory leaks
- Retain cycle detection
- Instruments
- Memory Graph
- Startup time
- Rendering issues
- Large-list optimization

## What You Should Be Able To Explain

- How to approach a laggy app
- How to find leaks and retain cycles
- Why the UI drops frames
- What affects startup time
- When optimization is necessary and when it is premature

## Practice Questions

- If a screen scrolls poorly, what do you check first?
- How do you approach a random production crash?
- Why can image loading make an app feel janky?

## Senior Notes

- Answer with a process: observe, isolate, measure, fix, verify.
