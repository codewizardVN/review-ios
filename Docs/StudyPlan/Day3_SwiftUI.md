# Day 3: SwiftUI

## Goal

Understand SwiftUI state flow and view lifecycle.

## Topics

- `View` lifecycle
- `@State`
- `@Binding`
- `@ObservedObject`
- `@StateObject`
- `@EnvironmentObject`
- Navigation
- Rendering performance

## What You Should Be Able To Explain

- When to use each property wrapper
- Why `@StateObject` matters for object ownership
- One-way data flow in SwiftUI
- Common mistakes that cause unnecessary re-renders
- When bridging to UIKit makes sense

## Practice Questions

- Why does a view keep reloading?
- When is `EnvironmentObject` appropriate, and when is it abuse?
- If a large list is laggy, where do you start debugging?

## Senior Notes

- Senior-level SwiftUI is not just about building UI quickly.
- The real focus is state ownership, side effects, performance, and architecture fit.
